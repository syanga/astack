## Claude Code preferences

* Before your first Bash `run_in_background` command, read `run-job/SKILL.md` from the installed skills. Run every background command through that skill's `run_job.py`, as the entire Bash command. Put `cd`, redirects, and pipes inside `sh -c '...'`.
* Before you end the turn with a watcher running, read its first check and confirm it ran without errors.
* Stop a background job with TaskStop when you replace it or no longer need it. Before starting a replacement that needs the same locks or ports, wait for the stopped job's exit notification.
* Run any checks before a PR merge as separate commands. Then run the merge as the entire Bash command: `gh pr merge <number> [--repo <owner>/<repo>] --match-head-commit <sha> [flags]`. Keep it on one line, with literal values, separate flags, and no quotes or shell syntax. Without `--auto`, `--match-head-commit` refuses the merge if the head moved after your checks. The merge gate hook denies every other Bash command that contains `pr merge` or a merge API path or name, such as `pulls/<n>/merge` or `mergePullRequest`. Write prose that mentions them, such as a commit message or PR body, to a file with the Write tool. Pass the file with `-F` or `--body-file`. Search for them with a pattern that breaks them up, such as `pr.merge`.
