# Session pickup

Read the prior trail and reuse completed work.

## Locate the prior work

Use the supplied handoff, plan, map, branch, or task-scoped conversation link. Read its overview and latest handoff first, then follow decision pointers as needed. Read the suggested skills for the remaining work.

Use the active environment's transcript tools or documented paths only for this task. For a long transcript, follow [guard the context window](../principles/guard-the-context-window.md), using a focused reader subagent when available and permitted. If the trail is unavailable, reconstruct what you can from the named artifacts and state what context is missing.

## Resume with an execution store

Follow [STATE.md's resume procedure](../orchestrate/STATE.md#resume) for ownership, evidence, standing orders, and the next action. Skip the steps for other work below, then report the outcome.

## Resume other work

1. Reconstruct the current state. Check the branch and worktree, what landed, pending work, and recorded decisions. For Wayfinder, read the map and current claims through its chosen tracker. Confirm the prior owner has stopped or transferred the scope before taking over writes. Apply recorded holds before verification or writes. A session change alone does not release a hold.
2. Verify inherited claims against the original goal through [prove it works](../principles/prove-it-works.md). Reuse evidence that identifies the current artifact and meets the receiving skill's acceptance rules. Recheck claims when relevant code, environment, or acceptance criteria changed, or supporting evidence is missing. Explain why a repeated check is needed. Report any check prevented by a hold as pending.
3. Select the next action from the verified state. Decide whether to continue execution, deliver completed findings, revisit a prior conclusion, or investigate a failed run. Keep the action within the hold's scope and remaining approvals.
4. Continue through the matching astack skill within the user's authorization. That skill owns execution and task-specific acceptance.

## Report

Report where the prior agent stopped, the evidence reused, any repeated checks and their reasons, and what happened next. For a handoff or final reply, follow [handoff's reporting procedure](SKILL.md#report).
