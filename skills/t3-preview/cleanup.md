# Preview cleanup record

Keep `preview-cleanup.md` outside the served directory and link it in the handoff. Record the owning worktree/thread, generated paths and retention decisions, public URL, and tab ID when available. For processes, include PID, start time, command without secrets, working directory, port, and supervisor; mark HTML-only previews as having none.

Update after restarts. When cleanup is authorized, follow [worktree-cleanup](../worktree-cleanup/SKILL.md) and record the outcome.
