# Ship PRs

Follow [PR follow-through](../harden-pr/pr-work.md) to take an existing PR or stack through remaining blockers to an authorized merge.

For a standalone shipping request, finish required post-merge verification and
follow [worktree-cleanup](../worktree-cleanup/SKILL.md) when all requested PRs
are merged. When another workflow owns further work, return the merge result to
that owner for closeout after its remaining steps.
